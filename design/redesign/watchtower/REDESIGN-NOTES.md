## 一、改了什么

本次是**视觉换装**，不动业务逻辑与数据流。规模（`git diff --stat` 实测）：14 个文件修改、
2 个新源文件（`lib/theme.ts` 149 行、`styles/reports.css` 625 行），+646 / −1101 行。
tsx 侧改动只有 4 个文件共 51 行——其中 44 行是设置页新增的「外观」行，5 行是 main.tsx 的
主题初始化接线，其余 2 行是死类删除。所有页面组件（Dashboard/History/Dispositions/Reports/
Settings 及各卡）的业务代码零改动。

设计语言一句话：**深色「瞭望塔」**——炭蓝表面阶梯 + 琥珀信号色 + 衬线页题；层次靠表面逐档
提亮和 1px 低透明度边框，不靠重阴影；卡片平面化，只有浮层（保存栏、主按钮、报表浮条）用
扩散阴影。**浅色「晨报」**是同一套变量名整体换值的暖白冷调版。

### 共享层（theme.css / base / primitives / shell / global.css + lib/theme.ts）

- **theme.css 整体重写**（332 行，四块结构）：① 深色基线持有全部新原语令牌（表面阶梯
  `--surface/-2/-3/-hi`、文字色阶 `--fg/--muted/--faint`、琥珀 `--accent` 族、语义色
  `--ok/--err/--warn/--info` 族、独立输入边框与焦点环）；② 浅色覆盖块按属性选择器换值；
  ③ 旧 R12 变量名衍生层——约 1300 处旧引用不改一行 CSS 自动换相；④ 遗留别名层原样保留。
  旧的霁蓝品牌色（#2563EB 系）与恒假媒体查询暗色块全部清除。
- **品牌色从霁蓝换成琥珀**：主按钮、选中态信号、focus ring、概念「信号点」全部走 accent。
- **衬线标题**：新增 `--font-display` 系统衬线字体栈（Noto Serif SC / Songti SC / SimSun…），
  只授权三处——五页页题、日报日题、设置组头，字重 600。700 字重只剩 KPI 大数字两处（等宽栈）。
- **卡片与边框**：`.card` 改 1px 边框分层、阴影降为 no-op；卡头底带清除（层次交给底线）。
  按钮族、开关、chip、输入框、选中行按概念稿语言换装（详见 SPEC §3.3）。
- **滚动条**：改 10px 细条配方（thumb surface-3、悬停提亮、轨道透明）。
- **styles/reports.css 拆出**：原 events.css 的日报页段（约 610 行）机械拆成独立文件，
  拆分阶段经逐字节比对零改写；`global.css` import 保序登记（reports 必须在 primitives 之后）。
- **lib/theme.ts 新建**（149 行）：主题切换机制，只用标准 Web API，模块顶层无副作用；
  `main.tsx` 在 render 之前调用 `initTheme()` 写 `data-theme`，避免首帧闪错主题。

## 二、两套主题与外观切换

- **默认深色「瞭望塔」**：全新启动（无本地存储）首帧即深色，无需任何设置。
- **切换入口**：设置页 → 「运行与通用」组 → **「外观」**行（RunPaceCard 尾部），三选一：
  - **深色 · 瞭望塔**
  - **浅色 · 晨报**
  - **跟随系统**（OS 外观变化时应用实时翻转，选项保持停在「跟随系统」）
- **即时生效、独立记住**：点选立即换装，存于 localStorage 键 `fw-theme`（`theme.ts:36`），
  重启记忆。它**不进草稿/保存栏机制**——保存栏对它无效是正确行为，也不会把监控配置标脏。
- **原生控件跟随**：`color-scheme` 双保险（CSS 声明 + JS 写入，`theme.ts:109`），单选、滚动条、
  日期输入、select 在两主题下自动转向。
- **走查后门**：URL 加 `?theme=dark|light|system` 可一次性覆盖（不持久化，刷新即回到存储值）。
- **异常兜底**：隐私模式 / 存储被禁时静默回退默认深色，不崩溃。

## 三、怎么本地查看

```bash
npm install   # 已装过可跳过
npm run dev   # 启动 Electron 开发态
```

启动后按第二节切到浅色、再切「跟随系统」改 OS 外观各走一遍；五页（监控台/去向/历史命中/
日报/设置）都过一眼。浏览器/web 部署形态可加 `?theme=light` 直达浅色。

## 四、刻意没做什么

对照 SPEC §1.2 负面清单，以下事项**明确不做**，不是遗漏：

- **不做自定义标题栏**：保留 Electron 原生窗口框（无 `frame:false`）；概念稿的假窗口、
  红绿灯演示件不迁移。
- **信息架构 / 导航零变更**：侧栏五分区、设置六组、keep-alive 页宿主、锚点深链、键盘
  roving 全部原样。合并导航属产品决策，超出本次范围。
- **不加任何新数据功能**：概念稿的 7 段去向分布条、stat 卡走势 sparkline、countUp 数字滚动、
  7 秒假命中流、抽屉、toast、面包屑式 NEW 标流——全部不迁移（前两者需要新数据面，其余是
  演示件或与现有反馈重复）。
- **零网络字体、零图标库**：衬线标题只用系统字体栈；不打包、不引入任何字体文件。跨平台
  降级是既定代价：Windows 落宋体（SimSun），Linux 可能落黑体。
- **不做无限循环装饰动画**（项目纪律）；`prefers-reduced-motion` 全局熔断保留。
- **不照搬概念稿栅格**：概念按 1480px 画，应用窗口默认 980×700、最小 960——所有栅格按
  960px 宽验证，只取形制与令牌。
- **类名零改动**：类名是运行时行为契约（querySelector），本次仅删两个 tsx 死类拼接与一个
  CSS 死类（`.hit-mark`，tsx 零使用实测）。

## 七、怎么回退

改动**全部留在工作区、未提交**（`git status` 可复核）。回退分两步：

```bash
# 1. 恢复 14 个被修改的文件（均为 src/renderer/src 内的跟踪文件）
git restore src/renderer/src

# 2. 删除两个新增的未跟踪源文件
rm src/renderer/src/lib/theme.ts src/renderer/src/styles/reports.css
```

- 第 2 步不做的话，`reports.css` 已不在 `global.css` import 列表里（restore 已还原该文件）、
  `theme.ts` 无人引用（main.tsx 已还原），留着只是死文件，但建议一并清理。
- `design/redesign/watchtower/` 目录（含本文件与 SPEC 等文档）也是未跟踪的，纯文档、不含
  代码，回退应用不需要动它；留不留取决于是否还想查阅。
- 回退后即回到上一提交（`069a64c`）的界面，无残留配置——主题偏好存在 localStorage 键
  `fw-theme`，回退后旧代码不读它，无需清理；想清理可在任意页面控制台执行
  `localStorage.removeItem('fw-theme')`。
