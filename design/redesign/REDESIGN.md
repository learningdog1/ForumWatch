## 1. 摘要与设计原则

### 1.1 一句话概括

ForumWatch（Electron 桌面、托盘常驻、多论坛监控 + 推送、中文界面、数据全本地）的五个界面按「错误是一等公民、可解释性前置、活列表阅读优先」三条主线重做：tab 改名重排（流水→**去向**、今日回顾→**日报**），设置 17 卡收拢为**六组 + 锚点子导航 + 吸底保存栏**，全局补齐错误态/快捷键/可达性，视觉 token 从现状蓝灰中性系换成 MASTER 生成的**运营绿状态页体系**（浅暗双主题、对比度全实测）。

### 1.2 六条设计原则（一切决定的推导起点，ia §0）

1. **看 / 改分离**：四个查看页 + 一个设置页，侧栏一条分隔线切割，不在查看区内部再分组。
2. **可解释性前置**（product-context §3.3：差异化卖点）：「为什么没推送」必须是侧栏一眼可懂的名字（去向）+ 最短排障路径，不是空态里的一句提示。
3. **draft 单源**：设置一切修改走 draft → 保存生效；子导航是锚点不是路由，就是为了不拆散单一数据源。
4. **错误是一等公民**（audit 问题 #1；dsn §7 红线）：所有数据面「失败 ≠ 空」，统一错误条 + 重试 + 旧数据保留。
5. **活列表阅读优先于新鲜度**：用户正在读列表时，自动插入/自动刷新让位，「N 条新」角标承接（LogView 跟随暂停范本推广到全应用）。
6. **键盘优先**：导航、保存、列表移动都有快捷键，焦点环常显。

### 1.3 评审状态（如实记录）

- 共 **3 轮独立评审**，遗留中/高优先级问题 **1 个**。
- **通过界面：全局、监控台、去向、历史命中、日报**（「设置」界面未在该评审结论的通过名单中列名，本稿如实记录，不推断其状态）。
- **遗留问题（medium，唯一）**：上轮 medium 的修复引入新的层级问题——设置页错误覆盖层 `z-index` 提到 120 后同时盖过了 leavebar（100）。证据：`prototype/index.html:3399` `setErrOverlay` cssText `z-index:120`（注释「120 > savebar(95) > 演示面板(90)」，是修复上轮「savebar(95) 盖 overlay(30)」时的断值）；`:617` `.leavebar { z-index: 100 }`；`:618` 演示面板 `z-index: 90`。层叠关系（本轮通读分析）：leavebar 是 body 级 fixed 屏幕底部居中；错误 overlay 是 absolute 覆盖整个 `#screen-settings` 且背景不透明（`background:var(--bg)`）；两者同处 root 层叠上下文，120 > 100。复现路径：设置页改一字段（dirty）→ 演示面板选「设置 · 读取失败」→ 点侧栏任一分区 → `switchScreen` 弹出 leavebar（本 session 核实为 `index.html:1815-1821`）但被遮；演示面板（z-index 90）同被盖，无法用面板切回其他场景，逃生只剩错误卡内的「重试」。上轮该问题不存在（当时 overlay 30 < leavebar 100）。
  **修法（已定）**：overlay 取值改到 **96–99** 区间（大于 savebar 95、小于 leavebar 100）。实施阶段 0 前先在原型上核销此值，再进入 src 迁移。

## 2. 现状问题（审计要点，audit.md）

### 2.1 总体判断

现状是**成熟度相当高**的自建界面：零框架零组件库但有纪律严格的 token 体系、统一空态组件、统一图标系统、暗色整组覆盖、多处超出一般水准的细节（日志跟随暂停、IME 组合处理、请求序号守卫、dirty 守卫）。重设计不是推倒，是**修四个系统性层面 + 继承十项资产**。

### 2.2 四个系统性问题层面

1. **错误态系统性缺失**（最高优先级）：8 个数据面里 6 个失败被静默吞掉、与空态混淆（`catch → 置空`模式）；设置页 getConfig 失败 = 永久 loading（audit §5.2 全表）。
2. **命名与 IA**：「流水」会计隐喻不传达价值（价值只写在空态 hint）、「今日回顾」名不符实且与页内名「日报」两套并存；设置 17 卡单列长滚无导航、保存栏不吸底。
3. **口径一致性**：统计面板（固定 14 天）与列表（默认 7 天随筛选变）两套口径 UI 无解释；来源显示名三页两种（NodeSeek vs nodeseek）；同一静音状态文案两处漂移。
4. **数据密集场景打磨不足**：列表查询整屏闪 loading（搜索防抖每 300ms 闪一次）、分页只有前后翻、路由规则顺序=优先级却要「删除重加」、自动刷新无暂停、200 条环无阅读保护。

## 3. 设计系统（token 定稿 + 新旧映射）

### 3.1 来源与甄别

MASTER 由 ui-ux-pro-max `--design-system --density 8 --variance 3 --motion 2` 生成，产品归类 Status Page / Incident Management，匹配 Style 为 Minimalism & Swiss（Light+Dark 双支持）——分类与定位核对相符，**采用**。但 MASTER 是通用生成物，dsn 已逐条甄别（dsn §2–§5），本稿继承其结论：

- **不采用**：营销落地页 Section Order / CTA 漏斗；Orbitron 标题字体（无中文字形、气质与 Swiss 冲突、桌面离线不应依赖网络字体）；GSAP Scroll Reveal 实现（无 GSAP 依赖，保留 300–400ms 缓出参数精神）；移动端 375/768 断点。
- **改写为桌面规则**：响应式断点 → 最小可用窗口 ≥960px、列表区禁止意外横向滚动、「内容不横向溢出」原则保留。
- **升级为面板行为规范**（MASTER 落地页 telemetry 规则的转用，dsn §2）：①标「实时」必须有据——带更新时间与 stale 态；②轮询类 UI 提供暂停/频率控制；③窗口隐藏到托盘时停止 UI 层定时刷新与动画；④支持键盘操作；⑤`prefers-reduced-motion` 下直接渲染静态终态。
- **反模式区全部保留且权重只增**：慢仪表盘、装饰性图表、隐藏错误状态、emoji 图标、不可见焦点、0ms 状态突变、<4.5:1 对比度。

### 3.4 字体与字号

- **字体栈**：界面 = 系统中文栈（`-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC"`），免网络依赖；数据（时间戳/计数/指标值/日志/URL/ID）= mono 栈 + `font-variant-numeric: tabular-nums`（现状全局 tnum 保留）——列表刷新时数字不抖动。
- **Orbitron 不采用的完整论证**（dsn §3）：无中文字形（中文界面全量 fallback，混排基线字宽不一致）；气质（cyberpunk/tactical）与已选 Minimalism & Swiss 直接矛盾；桌面离线工具不应依赖 Google Fonts。mono 保留（JetBrains Mono 或系统等宽兜底），仅用于数据。
- **字号阶**：12px（时间戳/计数/卡题/aux/徽标/hint/日志行，**仅辅助元信息，禁正文**）/ 13px（来源行、按钮、次级正文）/ **14px（新增档：命中标题、日报正文等正文级）** / 15px（state-pill、组头、操作反馈）/ 20px（页题、四格指标数值——启用现状定义未用的层级，修 audit #15）。`--fs-28` 删除：密度 8 状态页不需要 hero 大数字。
- **中文排版参数**（MASTER 未覆盖、必须补）：正文行高 1.6–1.75（日报正文 1.7）；紧凑单行列表 1.4 起步；正文基准 14–16px；徽标 nowrap 不折行（Compact Label Overflow 反模式）。

### 3.5 间距 / 圆角 / 阴影 / 动效

- **间距**：MASTER 密集表 `--space-xs..3xl` = 2/4/8/12/16/24/32px；列表行内边距 8px 起；卡间距 12px；组间距 32px。**迁移注意**：现状 `--space-5: 20px` 在新阶无对应档，引用处须重映射到 16 或 24（阶段 0 一次性处理）；history.md 另要求补 `--space-05: 2px` 档（sparkbar 柱距）——与 `--space-xs` 同值，直接用 `--space-xs`。
- **圆角**：两档——卡 12px、控件（chips/按钮/输入）8px。现状三档（6/10/14）收敛。
- **阴影**：四档 sm/md/lg/xl（MASTER 值）；暗色层次以底色差+边框为主，不靠重阴影。
- **动效（motion 2/10）**：全部过渡 120–180ms（通用）/ 150–300ms（交互反馈）；一次性微交互 300–400ms 缓出（命中行入场、角标淡入、面板切换）；**移除现状状态点 2.4s 呼吸动画**（无限循环违反红线）；`prefers-reduced-motion` 直接渲染终态；窗口隐藏到托盘时 UI 层动画与定时刷新全部停止（引擎抓取不受影响）。

### 3.6 密度与挂机（dsn §6）

密集不等于拥挤：行间保留 8px 级呼吸位；中文小字 ≥12px；可见时列表刷新用增量插入，禁止整列表重排；虚拟列表**全应用不引入**（大数据面已被分页或 200 条环约束，见 §6.2——唯一例外是日报长文档用 `content-visibility` 文档手段）。

### 3.7 落地红线（dsn §7，验收 §8 逐条对照）

禁 emoji 图标（统一 SVG，Lucide 同风格 16×16 / stroke 1.5 / currentColor / aria-hidden，沿用现状 icons.tsx 栅格）；禁隐藏错误状态；禁装饰性图表（统计只放决策数据）；禁 0ms 状态突变；两模式正文对比度 ≥4.5:1（新色对必须复测）；可点区域 ≥44px（现状桌面控件普遍 26-40px，prototype 以 `--hit: 44px` 红线值落了档，实施时以「可点目标 ≥44px 或等效间距补偿」执行）。

### 3.8 已知偏差与裁决（唯一两处，均已裁决）

1. **侧栏宽度**：ia「184px 量级保留」vs prototype 200px——量级一致非冲突，实施取现状 184px 不动（少一处壳层回归）。
2. **`--warn` 浅色值**：dashboard.md §2.1 写「沿用现状 #A85A00（接入后复测）」，prototype 已实测拆为 `--warn #D97706`（点）/ `--warn-text #8A4A00`（文字，白底 ≥5:1）——**以 prototype 为准**（它是对 dashboard.md「须复测」条款的执行结果），dashboard.md 的沿用值废止。

### 4.2 命名定稿（audit #3 的解法）

### 4.3 顺序与结构决定

- **顺序 = 数据新鲜度谱系**：事件驱动（监控台）→ 定时轮询 10s（去向）→ 手动刷新（历史命中）→ 每日快照（日报），侧栏自上而下就是「离现在多远」；且监控台↔去向紧邻使最高频排障动线（audit 反复出现的排查链）变成一跳。
- **不加组标题、不合并页面、不拆设置为多 tab**：5 项远未超载（主导航 ≤5）；去向与历史命中任务不同（查解释 vs 查记录）、数据形态与刷新档位不同，合并会把两种查询语义塞进一页；拆设置会稀释「设置=改配置」单一心智且 dirty 守卫要跨页追踪。
- **层级两档**：侧栏 primary / 设置子导航 secondary（更小字号视觉弱一档）。
- **快捷键**：`Cmd/Ctrl+1..5` 切分区；侧栏 active 补 `aria-current`（修 audit #10）。
- **保留资产**：dirty 圆点、底部迷你状态。

### 4.4 设置页信息架构（audit #2 的解法）

- **17 卡 → 六组**（完整映射无遗漏，分组依据是用户任务而非实现模块）：① 监控内容（价格规则从第 7 位前移，组序=配置依赖序）② 智能匹配（三散卡归拢，匹配测试台移出）③ 推送通知（「行为」卡的推送总开关并入推送策略）④ 运行与通用（轮询+每日总结+自启合并为「运行节奏」一卡；代理独立成卡——语义独立且是大陆用户高频配置）⑤ 数据与诊断（匹配测试台从配置流中段移到页尾，修「诊断工具打断配置流」）⑥ 关于。
- **子导航 = 页内左侧 152-160px 锚点栏**（非路由）：保住 draft 单源（一份数据面/一个 dirty/一个保存栏/一条 leavebar）；任何组内修改到保存的距离 ≤ 一屏；支持跨页深链（如历史命中零命中词 → 关键词卡锚点）。放弃顶部 chips（横排拥挤）与手风琴全折叠（折叠藏起的配置等于不存在的配置）。
- **渐进披露三级**：L0 子导航选组 → L1 组内卡片平铺不折叠 → L2 实体行收起为摘要行（统一推广到路由规则，配上下移按钮）→ L3 hint 常显 + 高级参数折叠。
- **配套结构修正**：废除 `.card-scroll` 280px 嵌套滚动（卡内列表自然高度，>8 条折叠 + 「展开全部 N 条」）；小卡合并消颗粒度不齐。

| 历史命中（数千条落盘） | 服务端分页 50/100/200 + 页码跳转；**放弃客户端虚拟化**（行高不定，分页已解决数据量） |
| 监控台最近命中 / 去向实时环（各 200 内存） | 不虚拟化，控制更新方式：增量插入 + 活列表规则 |
| 活列表规则（统一） | 视口不在顶部（scrollTop>8）或 10s 内有交互 = 阅读中；新数据不插入，进暂存，顶部「+N 条新命中 · 点击并入」角标（`role="status" aria-live="polite" aria-atomic="true"`，语境句非裸数字，不抢焦点，+99+ 封顶）；回顶/点击一次性并入，300ms 批量入场 |
| 去向 10s 自刷 | 三态暂停：悬停（移开 2s 自动恢复）/ 筛选激活（清筛选自动恢复）/ 手动（显式恢复）；暂停期常驻「数据截至」标注 |
| 去向历史日（IPC 全量返回，可达上千条） | 分段渲染：首屏 150 条 + sticky「继续加载 +150」；**不做触底自动加载**（滚动阅读中自动追加违反阅读优先）；筛选在全量数据上计算 |
| 日志（500 环） | 级别筛选 chips（info/warn/error + 计数）+ 跟随暂停保留 + 复制按钮 |
| 设置卡内列表 | 废嵌套滚动，自然高度 + >8 条折叠「展开全部 N 条」 |
| 加载态 | **保留旧数据 + 局部 busy**，禁整屏替换（修搜索防抖每 300ms 闪烁）；首载无旧数据才允许文字型占位；>1s 才考虑骨架；切换数据面（实时↔某日）允许文字型加载（旧日数据留着更误导） |
| 筛选状态 | 切分区返回后保留筛选、页码、滚动位置（依赖壳层 keep-alive） |
| 虚拟化总决定 | 全应用不引入（大数据面均被分页/200 环约束）；唯一文档类例外：日报长文用 content-visibility |

### 6.2 危险操作三层确认（ia §5.2）

| 层 | 操作 | 确认方式 |
|---|---|---|
| draft 域内删除（规则/来源/通道/路由） | 未保存前可逆 | **不弹确认**：转「待删除」态 + 保存栏「含 N 项待删除」+ 放弃修改一键还原 |
| 立即不可逆 | 导入备份（覆盖全部+需重启）、放弃修改（丢 N 处 draft）、日报重新生成（覆盖重写） | 确认：导入/放弃用确认层或行内确认条（danger 与 primary 视觉分离）；重新生成用行内确认条 |
| 破坏性导出 | 导出备份（**明文凭据**） | 双重警告前置 + 成功提示再提醒（保留强警告位） |

### 6.3 错误态（原则 4 的统一实现）

- 统一 **ErrorBar**：卡内顶部、err 弱底、`✗(SVG) 文案 [重试]`、`role="alert"`、**旧数据保留不替换**；事件订阅存活时首个后续事件到达自动消失。
- 覆盖面：现状 8 个数据面中 6 个静默面全部补齐（设置 getConfig 整页错误态 + 重试；日报双数据面独立错误；历史列表/来源下拉；去向实时/历史日；监控台三面 + control 命令行内失败反馈）。
- **错误与空态严格互斥**：加载失败永不落入「还没有记录」类空态。
- 诚实边界（详稿已声明，实施不掩盖）：主进程 queryHits/getStats 把单日文件损坏按空处理、loadReport 把读失败与无文件双吞为 null——渲染层错误条只覆盖 IPC 通道失败，彻底修法属主进程 P2 项（§7 阶段 6）。

### 6.4 空态（三态意识推广）

区分「从未 / 本会话无（或默认窗口无）/ 筛选后无」，每个空态给下一步动作或出口，无结果给建议禁死路。设置页适配为「空列表（行内灰字+指引）」与「零配置语义警示（常显 warn 条：包含词空=不推送、兴趣空=语义不命中、AI 未配置=降级）」两类分开讲。

### 6.5 反馈与 dirty 守卫

- **行内三态反馈，不建全局 toast**（桌面单窗口、操作在具体卡片上下文，行内最贴近因果）：进行中（busy，内容不替换）/ 成功（✓+时刻，简短）/ 失败（✗+原因+重试动作）；反馈区 `aria-live` 或 `role="alert"`。
- **saveMsg 生命周期**：dirty 一旦为真立即清除「已保存·时刻」，两者互斥绝不并存（修 audit #7）。
- dirty 守卫四件套：现状 dirty-dot + leavebar 非路由拦截 + 测试 dirty 闸保留，新增 ⌘S、放弃修改常驻吸底栏、**窗口隐藏不触发守卫**（关窗=托盘，组件不卸载 draft 留内存，重开原样恢复）。

### 6.6 键盘与可达性绑定（随各页落地，验收逐项查）

- 快捷键：`Cmd/Ctrl+1..5` 切分区（全局）；`⌘S` 保存（设置）；`/` 聚焦搜索（去向/历史）；`j/k`、`↑/↓` 列表行移动（roving tabindex，焦点环 2px 常显）；`Enter` 打开原帖/展开行；`P` 暂停/恢复（监控台引擎、去向自刷各按作用域）；`R` 立即轮询/手动刷新；`T` 测试通知/回今天；`PageUp/Down` 翻页（历史）；`Esc` 逐级退。单键仅在焦点不在 input/textarea 且非 IME 组合时生效。
- 可达性：Field 全量 `htmlFor` + id（现状零调用）；chips `aria-pressed`；侧栏 `aria-current`；投票按钮 aria-label（emoji 全换 SVG）；开关 `role="switch"` 保留；相对时间 title 带绝对时间戳。

### 6.7 口径一致性单源（audit §5.5 的结构性根治）

- **来源显示名**：全应用一处 `sourceLabel()` 映射，去向/历史/路由下拉三处共用（修 nodeseek vs NodeSeek）。
- **命中行组件**：全应用唯一 `HitRow`（监控台与历史命中共用，含投票与推送三态），静音 title 定稿文案「推送总开关关闭，或无就绪通道」（替换过时的「或 Telegram 未配置」）。
- **统计窗口口径**：数字旁必标窗口（「近 14 天」），列表筛选窗口独立标注。
- **测试 dirty 闸文案**归一为一句。
